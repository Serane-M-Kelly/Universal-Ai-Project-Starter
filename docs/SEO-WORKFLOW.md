# Utiliser le parcours SEO

Le référencement est traité selon l'enjeu réel du site. Aucune étape supplémentaire n'est imposée
à une liste de tâches privée, un dashboard ou une correction sans effet sur les pages publiques.

| Moment | Rôle | Résultat utile |
|---|---|---|
| Cadrage | PA, ou Discover si le brief est direct | Pages, intentions, contenus, langues, objectif et données connues. |
| Conception | AD | Contenus lisibles, liens et informations préservés dans les maquettes. |
| Préparation | Setup et Plan | Solutions adaptées, critères vérifiables, migration et suivi si nécessaires. |
| Réalisation | Phase et Review | Contrôles pertinents avec preuves et limites. |
| Publication | Ship | Vérification sur le vrai domaine après exécution manuelle. |
| Observation | Start puis Plan | Bilan à partir des données disponibles, corrections proposées au plan courant. |

## Nouveau site

Dans Codex, fournir les décisions produit et demander à Start d'intégrer les besoins SEO applicables.
L'agent réutilise le dossier PA ; il ne refait pas une étude de marché déjà suffisante. Les contenus
et critères restent dans le brief et leurs sources existantes. Une retouche ne rouvre que les points affectés.

## Refonte ou changement de domaine

Fournir ancien/nouveau domaine, contenus et URL accessibles, langues, puis exports de performances
s'ils existent. Le starter prévoit les correspondances, redirections et vérifications. L'absence
d'export ne devient pas une baseline de zéro. Une modification de code ne publie rien automatiquement.

## Site publié

Transmettre la cible et le résultat du déploiement à Ship. Les contrôles concernent la configuration
réellement servie, les redirections, langues et URL pertinentes. Fournir des observations ou exports
si les accès manquent. Demander ensuite un bilan après une période adaptée, avec une personne
responsable du suivi ; un rendez-vous dans le plan n'est pas un rappel automatisé.

## Lire le résultat

- **Techniquement conforme** : les critères applicables ont été vérifiés sur l'environnement nommé.
- **Publié** : la livraison est observée sur la cible, pour la version identifiable.
- **Indexé** : une observation réelle confirme cet état, distinct d'une simple demande d'indexation.
- **Performant** : les données et objectifs permettent d'examiner visibilité et actions utiles.

Le starter ne garantit pas la progression entre ces états. Les tests actuels ne prouvent ni la
visibilité d'un futur site ni une hausse de trafic. Voir le [guide complet](GUIDE-COMPLET-KELLY.md).
